# 赵倍庆个人 AI 系统免费云端定时器

这个公开仓库只负责每五分钟唤醒一次个人 AI 系统的加密调度接口；网站、账号、任务、成果和用户数据都不在这里存储。

## 为什么使用 GitHub Actions

- 不需要 Cloudflare 控制面板、付费套餐或本机常开。
- 使用公开仓库的 GitHub 标准托管运行器，当前路径不产生 Actions 费用。
- 调度密钥只保存在仓库的加密 Secret `SCHEDULER_TRIGGER_SECRET` 中，不写入源码和日志。
- 每月由定时任务自动提交一次 `.scheduler-keepalive`，避免公开仓库长期无活动时计划任务被自动停用。

## 工作方式

1. GitHub Actions 大约每五分钟启动一次。
2. 它向固定的生产接口发送带 Bearer Secret 的 `POST` 请求。
3. 生产系统自行扫描到期任务、抢占执行并记录结果；本仓库看不到任务内容。
4. 没有到期任务时正常结束，不产生业务成果。

## 安全边界

公开仓库只暴露本来就需要联网访问的接口地址。没有加密 Secret 的请求会被拒绝。请勿把 Secret 写入提交、Issue、运行日志或文档。
